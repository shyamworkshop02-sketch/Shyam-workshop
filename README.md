# Shyam Workshop and Engineering — Static Website

A responsive one-page website made with HTML, CSS and vanilla JavaScript. The supplied workshop/product photos are stored in `assets/`.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Before publishing
- Replace the generic WhatsApp URL (`https://wa.me/?text=...`) with the business WhatsApp number in international format, e.g. `https://wa.me/91XXXXXXXXXX?text=...`.
- Add the confirmed phone number, address, and any verified service details if desired.
- Review product captions and only publish claims that accurately describe the business.

## Files
- `index.html` — page content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `assets/` — supplied photos
